# GraphMath 1.0 — посібник

## Початок роботи

Розпакуйте весь ZIP і відкрийте GraphMath.exe. Python та Інтернет не потрібні.
Ліворуч — функції, у центрі — графік. Панель функцій можна закрити або змінити її
ширину перетягуванням межі. Ctrl+B повертає панель. Дослідження відкривається Ctrl+I.

Введіть `x^2 - 4`, `2^x`, `sqrt(x)`, `root(x,3)`, `log(x,2)`, `ln(x)`,
`1/x`, `sin(x)`, `cos(x)`, `tan(x)` або `abs(x)`. Префікс `y =` необов’язковий.
Множення записуйте явно: `2*x`, а не `2x`. Степінь — `^` або `**`.
`log(x)` і `ln(x)` — натуральний логарифм, `log(x,2)` — логарифм з основою 2.
Тригонометрія використовує радіани. Константи: `pi` (або π), `e`.
`root(x,3)` — дійсний кубічний корінь, у тому числі для від’ємних x.

Числові показники степеня обмежено діапазоном −100…100; також підтримано `2^x`.
Вирази з довільними змінними показниками, наприклад `x^(a+1)`, не підтримуються.
Дужки та кнопки математичного введення вставляють редагований текст із виділеним
аргументом. Під полем показується набрана математична формула.

## Функції і параметри

Натисніть «Додати функцію». Кольорове коло змінює колір, позначка ✓ приховує або
показує криву, меню ⋯ дублює чи видаляє функцію. Клацання кривої або поля обирає
функцію. Помилка в одному виразі не зупиняє інші графіки.

Для `a*x^2+b*x+c` автоматично з’являться окремі повзунки a, b, c. Кожна функція має
власні параметри. Меню ⋯ біля повзунка змінює мінімум, максимум і крок; ↺ повертає
початкове значення. До шести параметрів на функцію; x, e, pi зарезервовано.
Кнопка «Вмістити» масштабує y для вибраної функції у видимому діапазоні x.

## Керування графіком

Колесо миші змінює масштаб, перетягування переміщує площину. Наведення показує
координати курсора внизу та значення вибраної функції у підказці. Ctrl+0 скидає
вигляд. Сітка, осі, точність чисел, палітра, масштаб тексту та діапазон змінюються
через «Вигляд → Налаштування». Кнопка місяця перемикає світлу й темну тему.

## Дослідження

Відкрийте панель «Дослідження функції», за потреби оберіть другу функцію і натисніть
«Дослідити функцію». SymPy обчислює точні символьні властивості. Якщо алгоритм не
може надійно отримати результат, відображається відповідне повідомлення.
Обчислення обмежено вісьмома секундами; їх можна перезапустити після спрощення
виразу. Зміна функції чи параметра скидає старі результати.

Прапорці показують нулі, екстремуми, перетини та асимптоти. Нескінченні множини
нулів/асимптот можуть бути описані символьно без маркерів на площині.
Координати маркерів — числові наближення точних результатів. Дотична обчислюється
чисельно у вказаній точці й позначається як наближена; у розривах або виявлених
кутових точках вона не показується.

## Проєкти і експорт

Ctrl+S зберігає `.graphmath`, Ctrl+Shift+S — копію під новим ім’ям, Ctrl+O відкриває,
Ctrl+N створює порожній проєкт. Файл зберігає функції, кольори, видимість, параметри,
масштаб, положення, сітку та осі. Тема і глобальні налаштування зберігаються локально.
Тимчасові результати аналізу та його позначки повторно обчислюються після відкриття.
Нещодавні проєкти доступні в меню «Файл». Незбережені зміни позначаються ●.

Ctrl+Z / Ctrl+Y скасовують і повторюють зміни; у полі введення спершу працює локальна
історія тексту. Delete поза полем введення видаляє вибрану функцію. Escape закриває
панель дослідження. Ctrl+E експортує лише графік у PNG, SVG чи PDF. Для PNG можна
обрати прозоре тло. Збережений експорт містить поточні криві, осі й позначки.

## Обмеження точності

Це інструмент дослідження, а не система доведення. Скінченна числова вибірка може
пропустити особливість на дуже вузькому інтервалі або швидкі коливання. Збільшуйте
цікаву область. Біля полюсів криві розбиваються; далеко за видимим діапазоном вони
відсікаються. Повністю довільні символьні задачі не гарантуються. Наближені дотичні
не слід використовувати як точні докази. Від’ємні основи з дробовими степенями
вводьте через явний непарний корінь, наприклад `root(x,3)`.
