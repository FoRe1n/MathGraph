# Third-party software

The MIT license in LICENSE applies to original GraphMath code. Dependencies retain
their own licenses. The portable distribution includes complete license files
extracted from installed package metadata in `licenses/`, plus Qt's distributed
license texts. These notices are generated by `scripts/collect_licenses.py`.

- Python: PSF license (and bundled Python third-party notices).
- PySide6, Shiboken6, Qt: LGPLv3/GPLv3 or commercial terms as applicable. GraphMath
  uses Qt Core, Gui, Widgets, Svg and PrintSupport through dynamic libraries under
  LGPLv3. It does not intentionally use GPL-only Qt modules. Qt's libraries remain
  separate in the onedir distribution and can be replaced by compatible versions.
  Sources: https://download.qt.io/official_releases/QtForPython/pyside6/ and
  https://download.qt.io/archive/qt/6.8/6.8.3/submodules/ .
  LGPL text: https://www.gnu.org/licenses/lgpl-3.0.html .
  Users may modify/replace LGPL components and reverse engineer for debugging such
  modifications. No GraphMath restriction overrides those rights.
- PyQtGraph: MIT.
- SymPy, mpmath, NumPy, contourpy: BSD-style licenses.
- Matplotlib: Matplotlib license (PSF-based).
- DejaVu fonts (bundled with Matplotlib): permissive Bitstream Vera / DejaVu font licenses.
- Pillow: HPND and its included third-party notices.
- Packaging, pyparsing, cycler, kiwisolver, python-dateutil, six, fonttools:
  their included BSD/MIT/Apache or dual license notices.
- PyInstaller: GPLv2+ with the bootloader exception permitting distribution of
  non-GPL applications; included in generated license notices.

The GitHub repository includes the complete application and PyInstaller recipe,
allowing the application to be rebuilt against compatible replacement libraries.
Windows builds are unsigned. Windows may display its normal publisher/reputation
prompt; no Windows security settings need to be disabled to build or use GraphMath.
